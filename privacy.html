このツールについて

piyo-metrics は、運営者が自分の YouTube チャンネルの集計値を読み取るための個人用ツールです。運営者本人以外は利用しません。

取得する情報

YouTube Analytics API の読み取り専用の権限（yt-analytics.readonly）で、運営者のチャンネルの集計値（総視聴時間、登録者数の増減）だけを取得します。視聴者個人を特定できる情報は取得しません。

使い方と保存

取得した集計値は、運営者の手元のパソコンに保存し、運営者自身の振り返りにだけ使います。

第三者への提供

取得した情報を第三者に提供・販売・公開することはありません。広告にも使いません。

Google API の利用について

Google API から受け取った情報の利用と移転は、Google API Services User Data Policy（Limited Use の要件を含む）に従います。

許可の取り消し

許可は Google アカウントの「サードパーティ製のアプリとサービス」 からいつでも取り消せます。
