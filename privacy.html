このツールについて

piyo-metrics は、運営者が自分の YouTube チャンネルの集計値を読み取り、自分の記録に残すための個人用ツールです。運営者本人以外は利用しません。一般の利用者向けのサービスではありません。

このツールは YouTube API サービス（YouTube が提供する、プログラムからデータを読み取るための仕組み）を利用しています。このツールを使う人は、YouTube 利用規約に同意したものとみなされます。Google による情報の扱いについては、Google プライバシーポリシーをご覧ください。

Google アカウントで許可する範囲

許可するのは「YouTube Analytics の読み取り専用」の権限（yt-analytics.readonly）だけです。このツールは動画の投稿・編集・削除や、チャンネル設定の変更はできません。

取得する情報

運営者のチャンネルについて、YouTube Analytics API から次の集計値を取得します。どれもチャンネル全体や動画ごとに合計・平均した数字です。視聴者一人ひとりを特定できる情報（名前、アカウント、コメントの本文など）は取得しません。

  • 総視聴時間、チャンネル登録者の増えた数と減った数
  • 日ごとの再生回数・高評価の数・共有の数・コメントの数・視聴時間・登録者の増減
  • 期間全体の再生回数・視聴時間・平均視聴時間・平均視聴率（動画のどこまで見られたかの割合）
  • 再生回数の多い上位10本の動画の動画ID（動画ごとの識別番号）と、それぞれの再生回数・視聴時間・平均視聴時間・平均視聴率・高評価の数
  • 流入元（YouTube 検索、関連動画、外部サイトなど、視聴者がどこから来たか）ごとの再生回数と視聴時間

上位10本の動画のタイトルは、YouTube が公開している仕組み（oEmbed）に動画IDを送って取得します。このとき送るのは公開されている動画IDだけで、Google アカウントの情報は送りません。

使い方

取得した情報は、運営者がチャンネルの状況を振り返るための集計表と、週ごと・月ごとのレポートを作ることにだけ使います。取得は運営者のパソコンで週に1回（月曜日の朝）自動で行います。

保存する場所

  • 集計表とレポート（上で説明した数字に加え、上位10本の動画のタイトルと動画IDを含みます）: 運営者のメモアプリ（Obsidian）の保管場所に保存します。この保管場所は、運営者が管理する GitHub の非公開リポジトリ（アクセスを許可された人しか見られないオンラインの保存場所）へ自動で同期されます。また、同期ソフト（Syncthing）で運営者自身のほかの端末とも同期されます。
  • 動作の状況記録（どの週を処理したか、成功したかなど。数字は含みません）: 集計表と同じ保管場所に保存し、同じように同期されます。
  • 元データ（API から受け取ったそのままの数字と動画タイトル）: 運営者のパソコンの中だけに保存し（~/.local/share/piyo-metrics/raw/）、運営者本人しか読めない設定にしています。上の同期の対象には入れません。
  • 認証情報（Google が発行する、読み取りを続けるための許可の情報）: 運営者のパソコンの中だけに保存し（~/.config/piyo-metrics/token.json）、運営者本人しか読めない設定にしています。
  • 動作記録（ログ）: 運営者のパソコンに保存します。

ツールが保存するのは上のファイルだけで、Cookie（閲覧者の端末に情報を保存する仕組み）は使いません。

保存期間と削除

自動で削除されるのは元データだけです。ツールは実行のたびに（週に1回）Google の許可が有効かを確認し、次のどちらかに当てはまると元データを削除します。

  • 最後に許可を確認できた日から30日を超えたとき
  • 許可を確認できず、しかも最後に確認できた日から23日以上たっているとき

この削除はツールが動いたときに行われます。パソコンを止めているなどでツールが動いていない間は、削除も行われません。

集計表・レポート・動作の状況記録・認証情報・動作記録（ログ）は自動では削除されず、運営者が削除するまで残ります。運営者は、元データを手動で削除する操作（削除するものを確認してから実行）や、ほかのファイルの削除によって、いつでも情報を消せます。ただし、GitHub に同期された集計表・レポートは変更の履歴が残るため、完全に消すにはその履歴も削除する必要があります。

第三者への提供

取得した情報を第三者に提供・販売・公開することはありません。広告にも使いません。上で説明した GitHub への同期は運営者自身の記録を保管するためのもので、ほかの人に見せるためのものではありません。

Google API の利用について

Google API から受け取った情報の利用と移転は、Google API Services User Data Policy（Limited Use の要件を含む）に従います。

許可の取り消し

このツールへの許可は、Google のセキュリティ設定ページ（アカウントにアクセスできるアプリ）からいつでも取り消せます。取り消すと、ツールは新しい情報を取得できなくなります。元データは「保存期間と削除」の条件により、ツールが動いていればおおむね30日以内に自動で削除されます。
